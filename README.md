# Fake News Detection Using Deep Learning

## 📌 Project Overview

Fake News Detection is a deep learning-based project developed to identify whether a given news article is likely to be **Real** or **Fake**.

The project uses Natural Language Processing (NLP) and a trained deep learning model to analyze news text and generate a prediction.

## 🎯 Objectives

- Detect potentially fake news from textual content.
- Apply Natural Language Processing techniques to news data.
- Use a trained deep learning model for classification.
- Provide a simple interface for entering news and obtaining a prediction.

## 🛠️ Technologies Used

- Python
- Deep Learning
- Natural Language Processing (NLP)
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Tkinter
